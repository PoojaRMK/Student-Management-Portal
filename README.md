# Student-Management-Portal
Student Management Portal planned using Agile Scrum practices.
## **Project Overview**
The Student Management Portal is a proposed system to manage student information in a college.it aims to make student registration ,student records , attendance, and marks management easier.
## **Objective**
-Maintain student information.
-Provide student login and registration.
-Allow authorized users to update student records.
-manage attendance and academic marks.
-Organize development using Agile Scrum practices.
## **Main features**
1.Student Registration and login
2.Student Portfolio Management
3.Attendance Management 
4.Marks and Results MAnagement
5.Admin Management
## **Development Methodology**
This project follows Agile Scrum practices.The work is organised into a product Backlog and Sprint 1 plan.GitHub is used for version control,commits,and branches.
